# casion — 야바위 부스 게임

인터넷 없이 노트북 한 대에서 돌리는 야바위 게임입니다. 설계와 경제 수치는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.

## 부스에서 실행하기

1. (인터넷 되는 곳에서 한 번만) `npm install` → `npm run build`
2. 만들어진 `dist/index.html` 파일 하나를 노트북에 복사합니다.
3. 부스에서 그 파일을 더블클릭해 Chrome이나 Edge로 엽니다. 인터넷이 필요 없습니다.
   - 통계는 브라우저에 저장되므로 매일 같은 브라우저, 같은 파일 위치에서 여세요.

## 진행 방법

- **새 손님** → 손님에게 칩 6개를 받고 **시작** (참가비 1 + 게임 칩 5)
- `Space` 섞기 → `1`·`2`·`3` 또는 클릭으로 컵 고르기 → `Enter` 다음 판
- 한 판 1칩, 맞히면 3칩. 최대 8판, 칩이 0개가 되거나 +10칩을 따면 끝
- 정산 화면의 "돌려드릴 칩 N개"만큼 칩을 주고 **지급 완료**
- 쉬움·보통은 칩 없는 무료 연습입니다.
- `M` 소리 켜기/끄기

## 관리자 화면

화면 위 제목 **야바위**를 5번 연달아 클릭 → PIN (기본 `0000`).
통계(난이도별 적중률, 부스 순칩), 최대 판수(4~10), 소리, PIN, 백업(JSON), 초기화를 할 수 있습니다.
그 밖의 값은 `src/config/defaults.json`을 고치고 `npm run sim`으로 확인한 뒤 `npm run build`로 다시 만듭니다.

## 개발

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | `dist/index.html` 한 파일로 빌드 |
| `npm test` | 단위 테스트 (Vitest) |
| `npm run e2e` | 브라우저 테스트 (Playwright) |
| `npm run sim` | 경제 시뮬레이션 |
| `npm run typecheck` | 타입 검사 |
