# 영끌문S 설계서

> 게임성을 넣은 모의 트레이딩 게임. 완전 오프라인, 노트북 1대, 한 번에 플레이어 1명.
> 숫자는 모두 `npm run sim`(= `node scripts/simulate.ts`) 출력이다(4장). 조정값은 `src/config.ts` 한 곳에 있고, 앱과 시뮬레이션이 같은 값을 읽는다.

## 0. 한눈에 보기

- **화면:** 좌측 종목 탭 5개와 선택한 종목의 상세 설명, 가운데 선택한 종목의 캔들(막대) 차트, 우측 계좌·매수/매도·보유 종목.
- **차트:** 1초마다 캔들 1개(0.1초 틱 10개). 보조 지표는 없다. 게임 시작 전 150초 분량의 과거 차트를 그려 두고, 그 마지막 값이 종목의 시작가가 되도록 맞춘다.
- **돈:** 기본예탁금 **$1,000**로 시작. 매수할 때 증거금(투자 금액)과 레버리지(1·2·5·10·20배)를 고른다. 수수료는 주문 규모(증거금 × 레버리지)의 0.1%를 매수·매도 때 각각 낸다.
- **청산:** 손실이 증거금의 95%에 닿으면 강제청산되고 증거금을 모두 잃는다. 예탁금이 음수가 되는 일은 없다.
- **끝:** [정산하기]를 누르면 보유 종목을 모두 현재가로 팔고 결과를 보여 준다. 보유 종목이 없고 예탁금이 최소 주문($10 + 수수료)보다 적으면 파산으로 끝난다.

## 1. 운영 흐름

1. **시작 화면:** 규칙 요약과 [게임 시작](Enter). 뒤에서는 데모 시장이 돌아간다.
2. **게임:** [게임 시작]을 누를 때마다 새 시장(모든 종목이 시작가에서 출발)과 새 계좌($1,000)를 만든다.
3. **거래:** 좌측 탭(또는 ↑↓ 키)으로 종목을 고르고, 우측에서 매수 또는 매도한다.
4. **정산:** 상단 [정산하기] → 확인 → 결과 화면(최종 금액, 손익, 거래 횟수, 강제청산 횟수, 낸 수수료) → [처음으로](Enter).

## 2. 종목과 차트 모델

모든 종목이 같은 0.1초 틱으로 움직인다. 매 틱 모델이 로그 가격 변화량을 내고, 캔들의 고가·저가는 그 1초 안의 틱 중 최고·최저다. 종목마다 시작가 대비 가격 범위(`bounds`)를 벗어나면 서서히 끌어당기고, 시작가의 1%~100배는 절대 넘지 않는다.

| 종목 (티커) | 시작가 | 위험도 | 모델 | 설명 |
|---|---|---|---|---|
| 킹카콜라 (KKCL) | $64 | ★ | `steady` | 상승 구간(평균 30초)과 하락 구간(평균 12초)이 번갈아 온다. 잡음이 작다. |
| SK로우닉스 (SKLW) | $140 | ★★★ | `crash` | 가파르게 오르다가, 바닥 대비 상승폭이 4%를 넘으면 급락 확률이 상승폭에 비례해 커진다. 급락은 1.5~3.5초 동안 약 9~15%. "올라가는 것 같은데?" 할 때 떨어진다. |
| 돌지코인 (DOLGE) | $2 | ★★★★ | `wave` | 긴 파동(24~48초)과 짧은 파동(5~11초)을 겹친 추세. 반 파동마다 길이와 높이를 새로 뽑는다. 점프 없음. |
| 뭐더나 (MWDN) | $61 | ★★★ | `decay` | 꾸준히 하락. 초당 0.3% 확률로 2~5초 동안 16~42% 급등하고, 이후 15~35초에 걸쳐 그 상승의 40~70%를 반납한다. |
| 게이임스탑 (GGME) | $10 | ★★★★★ | `squeeze` | 가격 = 기준선 + 0.2초 반감기로 되돌아오는 편차 + 점프(초당 0.8회, 5~20%). 기준선은 잠잠함 → (40%) 숏스퀴즈(6~14초에 ×1.5~×3) → 덤핑 순서로 움직인다. |

## 3. 계좌 규칙 (`src/game/account.ts`)

| 항목 | 값 |
|---|---|
| 기본예탁금 | $1,000 (`economy.deposit`) |
| 레버리지 | 1·2·5·10·20배 (`economy.leverages`) |
| 주문 | 증거금 $10 이상(`economy.minOrder`). 증거금 + 수수료가 예탁금 이하일 때만. |
| 수수료 | 주문 규모의 0.1%(`economy.feeRate`), 매수·매도 각각, 1센트 단위로 올림 |
| 포지션 | 종목마다 하나(격리 증거금). 추가 매수는 같은 레버리지만 가능하고 평단은 가중평균. |
| 청산가 | `평단 × (1 − 0.95 / 레버리지)` (`economy.maintenance` = 0.05). 예: 10배면 평단 −9.5%. |
| 매도 | 25·50·75·100%. 받는 돈 = 증거금 × 비율 + 손익 − 수수료(0 미만이면 0). |

**꼼수 방지**
- 가격은 `crypto.getRandomValues`로 만든다. 다음 움직임을 미리 알 방법이 없다.
- 시장은 절대 멈추지 않는다. 정산 확인 창이 떠 있어도 틱과 강제청산이 계속된다.
- 매 틱 가격을 바꾼 직후 강제청산을 먼저 처리하고, 거래는 그다음 틱 전까지 화면에 보이는 그 가격으로 체결된다. 청산가 아래 가격에 팔 수 없다.
- 수수료는 올림이라 주문을 잘게 나눠도 싸지지 않는다. 증거금 입력은 숫자만 받고 센트 단위로 자른다.
- exe에서는 새로고침(F5, Ctrl+R), 개발자 도구, 확대/축소 키를 막는다. 게임 상태는 저장하지 않으므로 창을 닫으면 그 게임은 끝난다.

## 4. 시뮬레이션 (`npm run sim`)

seed 20261019, 400게임. 매 게임 새 시장을 만들어 시작가에서 출발한다.

|---|---|---|---|---|---|---|---|
| 킹카콜라 | +1.9% | -2.5% / +1.8% / +6.5% | 74% | +6.6% | -2.2% / +15.3% | -2.2% | +0.9% / -0.8% |
| SK로우닉스 | +4.9% | -11.5% / +5.2% / +20.9% | 69% | +13.2% | -17.1% / +46.3% | -14.7% | +2.7% / -12.8% |
| 돌지코인 | +0.1% | -17.2% / -0.2% / +17.7% | 50% | +1.1% | -21.2% / +25.3% | -18.4% | +7.8% / -7.2% |
| 뭐더나 | -7.3% | -16.6% / -11.1% / +11.1% | 19% | -23.3% | -39.6% / +1.1% | -15.9% | +12.8% / -2.5% |
| 게이임스탑 | +11.2% | -51.2% / +1.0% / +109.0% | 51% | +8.3% | -54.2% / +101.8% | -79.0% | +139.3% / -65.1% |

시작 즉시 매수해 3분 들고 있을 때(수수료 제외):

| 종목 | 5× 청산 확률 / 평균 수익 | 10× 청산 확률 / 평균 수익 |
|---|---|---|
| 킹카콜라 | 0% / +9.5% | 0% / +19.0% |
| SK로우닉스 | 4% / +23.1% | 35% / +25.3% |
| 돌지코인 | 10% / -1.8% | 57% / -23.8% |
| 뭐더나 | 2% / -36.9% | 70% / -64.2% |
| 게이임스탑 | 95% / -76.3% | 100% / -98.4% |

**밸런스 메모:** 지금 값으로는 "킹카콜라 고배율 장기 보유"가 가장 안정적인 전략이다. 상품·칩 교환 규칙을 정할 때 킹카콜라의 하락 구간 비중이나 최대 레버리지를 다시 본다.

## 5. 아키텍처

**Stack:** Vite + TypeScript (vanilla DOM, Canvas 2D), Vitest, Playwright, Electron(portable exe). Runtime dependencies: none.

```
src/
  main.ts            boot
  config.ts          모든 조정값과 타입 (scripts/simulate.ts도 같은 파일을 읽음)
  rng.ts             crypto RNG, seeded RNG(테스트·시뮬레이션), gauss
  game/market.ts     종목 모델 5종, Market(틱 → 캔들), 과거 차트 생성   (pure)
  game/account.ts    매수, 매도, 강제청산, 평가금액                    (pure)
  audio.ts           Web Audio 효과음 (매수, 매도, 수익, 손실, 강제청산 …)
  ui/app.ts          화면 배치와 게임 흐름, 0.1초 틱 루프
  ui/chart.ts        캔버스 캔들 차트 (평단·청산가 선 표시)
  ui/format.ts, dom.ts, style.css
tests/unit/{account,market}.test.ts
tests/e2e/smoke.spec.ts
scripts/simulate.ts
electron/main.cjs
```

## 6. 명령

| 명령 | 하는 일 |
|---|---|
| `npm install` | 의존성 설치 (Electron 포함) |
