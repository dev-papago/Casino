# 영끌문S 설계서

> 게임성을 넣은 모의 트레이딩 게임. 완전 오프라인, 노트북 1대, 한 번에 플레이어 1명.
> 숫자는 모두 `npm run sim`(= `node scripts/simulate.ts`) 출력이다(4장). 조정값은 `src/config.ts` 한 곳에 있고, 앱과 시뮬레이션이 같은 값을 읽는다.

## 0. 한눈에 보기

- **화면:** 좌측 종목 탭 5개(**난이도 쉬운 순**)와 선택한 종목의 상세 설명, 가운데 선택한 종목의 캔들(막대) 차트, 우측 계좌·매수/매도·보유 종목.
- **차트:** 1초마다 캔들 1개(0.1초 틱 10개). 보조 지표는 없다. 과거 차트 없이 시작가에서 출발해, 게임 시작 직후부터 왼쪽 끝에서 캔들이 쌓인다(`timing.historyCandles` = 0). 화면이 다 차면 스크롤한다. 시작 화면에서는 시세가 멈춰 있다.
- **무작위성과 경향:** 몇 초 앞은 동전 던지기에 가깝고(10초 방향이 다음 10초에 이어질 확률 51~55%), 종목의 경향은 게임 한 판(5분)에 걸쳐 높은 확률로 드러난다(킹카콜라 72%가 오른 채 끝남, 뭐더나 73%가 내린 채 끝남).
- **돈:** 기본예탁금 **$1,000**로 시작. 매수할 때 증거금(투자 금액)과 레버리지(1·2·5·10·20배)를 고른다. 레버리지는 평가 자산 $2,000부터. 수수료는 주문 규모(증거금 × 레버리지)의 0.1%를 매수·매도 때 각각 낸다.
- **청산:** 레버리지 포지션은 손실이 증거금의 80%에 닿으면 강제청산되고 증거금을 모두 잃는다. 1배는 빌린 돈이 없어 청산되지 않는다. 예탁금이 음수가 되는 일은 없다.
- **끝:** 게임 시간은 **5분**(`timing.sessionSec`). 장이 마감되면 보유 종목을 종가로 자동 정산한다. 그 전에 [정산하기]로 끝낼 수 있다. 보유 종목이 없고 예탁금이 최소 주문($10 + 수수료)보다 적으면 파산으로 끝난다.

## 1. 운영 흐름

1. **시작 화면:** 규칙 요약과 [게임 시작](Enter). 시세는 멈춰 있다.
2. **게임:** [게임 시작]을 누르면 새 계좌($1,000)로 시작하고, 시작 화면의 멈춰 있던 새 시장(모든 종목이 시작가)이 움직이기 시작한다. 상단에 "장 마감까지" 남은 시간이 나온다. 1분 전에 알림이 뜨고, 30초 전부터 시계가 빨갛게 깜빡인다.
3. **거래:** 좌측 탭(또는 ↑↓ 키)으로 종목을 고르고, 우측에서 매수 또는 매도한다.
4. **정산:** 장 마감(자동) 또는 상단 [정산하기] → 확인 → 결과 화면(최종 금액, 손익, 거래 횟수, 강제청산 횟수, 낸 수수료) → [처음으로](Enter).

## 2. 종목과 차트 모델

모든 종목이 같은 0.1초 틱으로 움직인다. 매 틱 로그 가격이 **종목 모델**(경향과 사건)만큼, 그리고 **공통 잡음**만큼 바뀐다. 캔들의 고가·저가는 그 1초 안의 틱 중 최고·최저다. 종목마다 시작가 대비 가격 범위(`bounds`)를 벗어나면 서서히 끌어당기고, 시작가의 1%~100배는 절대 넘지 않는다.

**공통 잡음** (`noise`): 가우스 잡음인데 그 크기가 잔잔한 구간과 출렁이는 구간을 오간다(로그 변동성이 평균 `wanderSec`초 동안 이어지는 OU 과정, 평균 분산은 `vol²`로 고정). 여기에 가끔 위아래 같은 확률의 점프가 섞인다. 이 잡음이 몇 초 단위의 추세를 가려서, 지난 캔들로 다음 캔들을 맞히기 어렵다. 경향은 몇 분이 지나야 보인다.

| 탭 순서 | 종목 (티커) | 시작가 | 난이도 | 모델 | 설명 |
|---|---|---|---|---|---|
| 1 | 킹카콜라 (KKCL) | $64 | ★ 쉬움 | `steady` | 상승 구간(평균 45초, 초당 +0.022%)과 하락 구간(평균 20초, 초당 −0.012%)이 번갈아 온다. 잡음 0.3%/√초, 가끔 0.4~1.2% 점프. |
| 2 | SK로우닉스 (SKLW) | $140 | ★★ 보통 | `crash` | 초당 +0.055%로 오르다가, 바닥 대비 상승폭이 5%를 넘으면 급락 확률이 상승폭에 비례해 커진다. 급락은 1.5~3초 동안 약 6~11%. "올라가는 것 같은데?" 할 때 떨어진다. 잡음 0.45%/√초. |
| 3 | 돌지코인 (DOLGE) | $2 | ★★★ 어려움 | `wave` | 긴 파동(40~90초)과 짧은 파동(8~16초)을 겹친 추세. 반 파동마다 길이와 높이를 새로 뽑는다. 잡음 0.8%/√초. 방향은 없다. |
| 4 | 뭐더나 (MWDN) | $61 | ★★★★ 고난도 | `decay` | 초당 −0.04%로 꾸준히 하락. 초당 0.2% 확률(5분에 0.6번)로 1~2.5초 동안 16~49% 급등하고, 이후 15~35초에 걸쳐 그 상승의 50~80%를 반납한다. 잡음 0.4%/√초. |
| 5 | 게이임스탑 (GGME) | $10 | ★★★★★ 극악 | `squeeze` | 초당 1.8% 확률로 +16~65% 급등(숏스퀴즈), 같은 확률로 −14~36% 급락이 0.1~0.4초 만에 일어나고 **그대로 머문다**. 급등 뒤에 급락이 따라오는 규칙이 없어서 고점 매도도 운이다. 그 사이 초당 −0.265%씩 흘러내려 평균 가격은 거의 제자리지만 중앙값은 반토막. 0.1~0.3초짜리 바늘(±4%, 초당 0.8번 3~10%)이 위아래로 튄다. |

난이도는 "1배로 사서 끝까지 들고 있을 때 수익이 나는 확률"(4장 B표 존버 행) 순서다: 72% → 71% → 48% → 27% → 28%(게이임스탑은 결과가 극단적이라 마지막).

## 3. 계좌 규칙 (`src/game/account.ts`)

| 항목 | 값 |
|---|---|
| 기본예탁금 | $1,000 (`economy.deposit`) |
| 레버리지 | 1·2·5·10·20배 (`economy.leverages`). 2배 이상은 평가 자산 $2,000부터(기본예탁금의 2배)(`economy.leverageFrom`). 그 아래로 떨어지면 1배만 새로 살 수 있고, 이미 보유한 레버리지 포지션은 유지된다. |
| 주문 | 증거금 $10 이상(`economy.minOrder`). 증거금 + 수수료가 예탁금 이하일 때만. |
| 수수료 | 주문 규모의 0.1%(`economy.feeRate`), 매수·매도 각각, 1센트 단위로 올림 |
| 포지션 | 종목마다 하나(격리 증거금). 추가 매수는 같은 레버리지만 가능하고 평단은 가중평균. |
| 청산가 | `평단 × (1 − 0.8 / 레버리지)` (`economy.maintenance` = 0.2): 2배 −40%, 5배 −16%, 10배 −8%, 20배 −4%. 닿으면 남은 20%까지 모두 잃는다. **1배는 청산 없음.** |
| 매도 | 25·50·75·100%. 받는 돈 = 증거금 × 비율 + 손익 − 수수료(0 미만이면 0). |
| 게임 시간 | 5분(`timing.sessionSec`, 0이면 무제한). 끝나면 종가로 자동 정산. |

**꼼수 방지**
- 가격은 `crypto.getRandomValues`로 만든다. 다음 움직임을 미리 알 방법이 없다.
- 차트 모양에 기대 이익이 생기는 규칙을 두지 않는다. 시뮬레이션의 봇(추세 추종, 저점 매수, 고점 매도 후 재매수)이 평균적으로 이기지 못하는 것을 확인했다(4장).
- 게이임스탑의 바늘은 0.1~0.3초 만에 사라진다. 사람이 보고 누르는 사이(0.3초 이상)에 이미 원래 자리라서 노려서 사고팔 수 없다.
- 시장은 절대 멈추지 않는다. 정산 확인 창이 떠 있어도 틱과 강제청산이 계속된다.
- 매 틱 가격을 바꾼 직후 강제청산을 먼저 처리하고, 거래는 그다음 틱 전까지 화면에 보이는 그 가격으로 체결된다. 청산가 아래 가격에 팔 수 없다.
- 수수료는 올림이라 주문을 잘게 나눠도 싸지지 않는다. 증거금 입력은 숫자만 받고 센트 단위로 자른다.
- 5분 장 마감이 있어서 오래 버티며 운을 기다리는 전략에 한계가 있다.
- exe에서는 새로고침(F5, Ctrl+R), 개발자 도구, 확대/축소 키를 막는다. 게임 상태는 저장하지 않으므로 창을 닫으면 그 게임은 끝난다.

## 4. 시뮬레이션 (`npm run sim`)

seed 20261019, 2000게임, 게임당 300초(5분). 매 게임 새 시장을 만들어 시작가에서 출발한다.

**난이도 목표**
- 몇 초 앞은 동전 던지기(10초 방향 지속 50~55%), 종목 경향은 5분 동안 높은 확률로 유지.
- 돈을 버는 확률(정산 때 수익): 여러 방식으로 플레이할 때 **약 40%**. 야바위 최상(2배를 34%로 맞힘)보다 조금 높게(주식은 시간이 드니까).
- 2배 이상: 가장 잘 노려도 **약 20%**.
- 10배 이상: 가장 공격적으로 노리는 플레이어 중 **1~2%**, 그 밖의 플레이는 거의 0%.

#### A. 차트

- **10초 방향 지속:** 지난 10초와 다음 10초가 같은 방향일 확률. 동전 던지기는 50%다. 매끄러운 추세는 80%가 넘는다(이전 버전 킹카콜라 79%, 뭐더나 85%).
- **매끄러움:** 30초 구간마다 `|순이동| ÷ 지나온 경로 길이`. 무작위 보행이 약 0.18이다(이전 버전 킹카콜라 0.65).

| SK로우닉스 | ★★ | +5.4% | -9.9% / +5.4% / +21.0% | 72.1% | 52.7% | 0.25 | +3.9% / -8.4% |
| 돌지코인 | ★★★ | +0.4% | -16.7% / -0.3% / +19.1% | 49.3% | 54.7% | 0.23 | +6.5% / -6.0% |
| 뭐더나 | ★★★★ | -4.9% | -20.4% / -6.8% / +16.6% | 27.4% | 53.2% | 0.25 | +17.0% / -4.4% |

게이임스탑의 방향 지속과 매끄러움이 낮은 것은 바늘 때문이다. 바늘은 사람이 잡을 수 없을 만큼 빨리 사라지므로 이용할 수 없다.

#### B. 플레이어 (게임 끝에 정산한 금액 ÷ 기본예탁금)

봇은 진짜 계좌 규칙(수수료, 청산, $2,000 레버리지 해금)으로 5분을 플레이하고, 사람처럼 1초마다 차트를 보고 **0.3~0.6초 뒤에** 그때 가격으로 체결된다.

- **존버:** 시작하자마자 1배로 사서 끝까지 들고 있는다.
- **2배 노리기:** 게이임스탑 1배를 들고 있다가 평가 자산 2.2배가 보이면 정산한다.
- **개미:** 몇 초마다 아무 종목이나 아무 금액·레버리지로 사고판다.
- **추세 추종 / 저점 매수:** 10초 동안 가장 크게 오른(내린) 종목을 산다.
- **한방 / 2배 후 …:** 게이임스탑으로 2배를 만들어 레버리지를 연 뒤, 고배율로 10배를 노린다.

**밸런스 메모**
- **2배 확률을 야바위(34%) 위로 올리지 않은 이유:** 게이임스탑 급등을 더 크고 잦게 해서 "2배 노리기"를 35%까지 올리면, "급등 뒤 고점에 팔고 다시 사기"의 평균이 2배 가까이 된다(시뮬레이션). 결국 더 후해진다. 2배를 기다리는 동안 흘러내리는 값이 모든 급등의 기대값과 맞아야 해서, 평균을 1배 근처에 두면 2배 확률은 약 20%가 한계다.
- **킹카콜라 고배율:** "2배를 만든 뒤 킹카콜라 20배"만 평균이 1배를 넘는다(1.16×). 킹카콜라가 높은 확률로 오르게 한 대가로, 오르는 종목에 손실이 증거금으로 끝나는 레버리지를 걸면 평균이 1배를 넘을 수밖에 없다. 막으려면 레버리지 이자(빌린 돈에 시간당 비용)나 낮은 최대 레버리지가 필요하다.
- **게임 시간:** 길어질수록 꼬리가 커진다. 10분이면 "2배 후 뭐더나 10×"의 10배 확률이 4.2%, "2배 후 킹카콜라 20×"의 평균이 1.46×다. 3분이면 10배 확률이 가장 높은 전략도 1.3%다. 그래서 5분 장 마감을 둔다(`npm run sim 2000 180`처럼 시간을 바꿔 확인).

## 5. 아키텍처

**Stack:** Vite + TypeScript (vanilla DOM, Canvas 2D), Vitest, Playwright, Electron(portable exe). Runtime dependencies: none.

```
src/
  main.ts            boot
  config.ts          모든 조정값과 타입 (scripts/simulate.ts도 같은 파일을 읽음)

  game/market.ts     종목 모델 5종 + 공통 잡음, Market(틱 → 캔들)          (pure)
  game/account.ts    매수, 매도, 강제청산, 평가금액                        (pure)
  audio.ts           Web Audio 효과음 (매수, 매도, 수익, 손실, 강제청산 …)
  ui/app.ts          화면 배치와 게임 흐름, 0.1초 틱 루프, 장 마감
```
